# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Основная аудитория — русскоязычные любители футбола и хоккея 23–45 лет,
которым нужен быстрый технический разбор предстоящего матча без самостоятельного
изучения множества таблиц. Пользователь хочет понять вероятности исходов,
ожидаемые голы и надёжность расчёта, а затем при необходимости получить
обновления в Telegram.

## Product Purpose

BetValue AI объединяет расписание, результаты и историю команд, рассчитывает
вероятности модели и объясняет ограничения расчёта. Успех продукта — пользователь
за короткое время понимает контекст матча и возвращается за следующими разборами.

## Positioning

Не «угадывание» результата и не витрина ставок, а прозрачная спортивная аналитика:
версия модели, вероятности, исходные данные и уровень неопределённости показываются
вместе. При недостатке истории сервис не публикует искусственные проценты.

## Operating Context

Пользователь открывает ближайшие матчи на публичном сайте, фильтрует их по виду
спорта и лиге, изучает отдельный матч и переходит в Telegram-бот для расписания
и будущих персональных уведомлений.

## Capabilities and Constraints

- Футбол и хоккей.
- Источники матчей: football-data.org и API-SPORTS.
- Русские отображаемые названия с сохранением исходных названий в API.
- Базовая модель Poisson v1 рассчитывает П1, Х и П2 по завершённым матчам лиги.
- Расчёт выводится только при достаточной истории; иначе показывается статус подготовки.
- Публичный сайт работает поверх отдельного API на Render.
- Telegram-бот показывает ближайшие события.
- Источник коэффициентов и EV не подключены и не должны изображаться работающими.

## Brand Commitments

Название продукта — BetValue AI. Голос спокойный, технический и проверяемый.
Запрещены обещания выигрыша, «железные прогнозы», агрессивная букмекерская подача
и преуменьшение неопределённости.

## Evidence on Hand

- Работающий публичный API матчей.
- Публичный сайт с реальными ближайшими событиями.
- Telegram-бот @BetValueAI_bot.
- Реализация и тесты модели Poisson v1.
- Подключённые источники football-data.org и API-SPORTS.
- Нет подтверждённой статистики точности, отзывов или коммерческих результатов;
  будущие страницы не должны их выдумывать.

## Product Principles

1. Реальные данные важнее эффектных обещаний.
2. Неопределённость показывается рядом с вероятностью.
3. Каждый экран должен давать самостоятельную аналитическую пользу.
4. Основной путь пользователя короткий: матч → расчёт → Telegram.
5. Аналитика отделена от любой будущей партнёрской рекламы.

## Accessibility & Inclusion

Основные действия доступны с клавиатуры и на мобильных устройствах. Состояния
не должны передаваться только цветом; интерфейс и тексты остаются понятными без
знания профессиональной статистической терминологии.
